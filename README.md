## 💻 Instrucciones de Uso

### Uso en Google Colab (Recomendado)
Para la mayoría de los notebooks no necesitas instalar nada en tu computadora. Solo navega a la carpeta del curso correspondiente, abre el archivo `.ipynb` y utiliza el botón de **Open in Colab** para ejecutarlo directamente en tu navegador.

### Clonado Local
Si deseas tener los archivos en tu máquina:
```bash
git clone https://github.com/JntnAG/MachineLearning_UQ_UTP.git
cd MachineLearning_UQ_UTP
```
Se recomienda crear un entorno virtual para correr las prácticas locales.
